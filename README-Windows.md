# Bambi para Windows

La misma Bambi de la tele (catálogo de TMDB, fuentes con tu servicio debrid, perfiles, Trakt) en el PC, con el mismo
aspecto y manejable con teclado, ratón o mando.

- **Instalar:** abre `Bambi-Windows-Setup-<versión>.exe` y sigue el asistente (en español): eliges la carpeta y crea
  los accesos del menú Inicio y del escritorio. No pide permisos de administrador. Se desinstala desde Configuración →
  Aplicaciones. Lleva su propio Java y su reproductor (mpv): no hay que instalar nada más.
- **Configurar:** la primera vez, una guía te pide la clave de TMDB (gratis) y la de tu servicio debrid, con el enlace
  a cada página. Las claves se guardan cifradas.
- **Manejo:** teclado, ratón o mando de Xbox; F11 para pantalla completa.
- **Detalles** (stack, atajos de teclado, diferencias con la tele, cómo compilar y estado de cada función):
  [docs/WINDOWS.md](docs/WINDOWS.md). Cambios: [CHANGELOG-Windows.md](CHANGELOG-Windows.md).
